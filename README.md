# 厂级人员工作交接

厂级人员工作交接的线上化闭环，三段独立架构：**交接班输入 → 钉钉AI表格记录 → 交接班输出**。输入按九类规范记全记准，AI表格承载记录与完整性告警，输出生成人能看懂的时间顺序清单。当前处于规划与协作搭建阶段，**业务程序尚未实现，不能用于生产交接**。

## 首版目标（2026-09-20 主控拍板）

- 输入九类（运行工况/设备/缺陷/隐患/重大事项/两票/作业外委/上级指令/其他），统一字段，发生时间必填精确到分。
- 钉钉AI表格两张表（班次表+交接事件表），四条完整性硬校验，告警直发交班人；有告警不允许生成清单。
- 输出为时间顺序清单，关键级置顶重点标记，只单发交班与接班两人。
- 接班确认走钉钉待办（关键逐项、一般整单），完成回写表格；可信身份源不唯一（钉钉/EAM/EHR，Probe-01 已实测）。

## 当前可以运行什么

仅运行仓库安全检查和其单元测试，不连接任何外部系统：

```text
python scripts/repo_checks.py
python -m unittest discover -s tests -p "test_*.py" -v
```

本地使用 Python 3.11 或更新版本执行以上检查。首次克隆后安装本地提交钩子：

```text
python scripts/install_hooks.py
```

本地钩子不是完整安全边界，远程 CI 才是合并检查依据。

## 隐私与许可

- 公开仓库不得放真实人员、交接记录、账号配置、个人绝对路径或文档署名；Git 作者记录正常保留。
