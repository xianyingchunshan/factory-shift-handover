# 厂级人员工作交接

厂级人员工作交接的线上化闭环：交班人按固定结构填写交接单，接班人逐项确认，双方确认留痕可查。当前处于规划与协作搭建阶段，**业务程序尚未实现，不能用于生产交接**。

## 首版目标（草案，待主控确认）

- 一班一张交接单，交接事项逐条列出、状态明确。
- 交班填写、接班逐项确认，双方确认均留痕，不由 Agent 代办。
- 未确认事项显式挂起，不自动视为已交接。
- 外部能力（确认渠道、提醒送达、可信身份）先经调查卡验证再依赖。

## 当前可以运行什么

仅运行仓库安全检查和其单元测试，不连接任何外部系统：

```text
python scripts/repo_checks.py
python -m unittest discover -s tests -p "test_*.py" -v
```

本地使用 Python 3.11 或更新版本执行以上检查。首次克隆后安装本地提交钩子：

```text
python scripts/install_hooks.py
```

本地钩子不是完整安全边界，远程 CI 才是合并检查依据。

## 隐私与许可

- 公开仓库不得放真实人员、交接记录、账号配置、个人绝对路径或文档署名；Git 作者记录正常保留。
- 本项目暂无开源许可证，公开可见不等于授予额外使用许可。
